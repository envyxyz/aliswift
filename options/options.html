AliSwift

Send AliExpress products to Google Sheets.

Sheets

AliSwift writes to the selected sheet. Each sheet keeps its own settings.

Create a Google Sheet (a native one, not an uploaded .xlsx), then add its link here. The first time you save a product, Google asks you to allow access.

Columns

Rows are added below the last filled keyword cell, never above the first data row.

Pricing

Use costPrice with + - * / and parentheses, e.g. (costPrice + 2) * 1.5

Sell price = cost price x (1 + margin / 100). A margin of 25 gives 125% of cost.

Cost price = item price + shipping (when the page shows it) + extra cost. Pricing starts from that total.
